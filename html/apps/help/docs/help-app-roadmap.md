# Help App Roadmap

## Current Status
- All theme documentation is now included in `/apps/help/docs/`
- Developer help section references new theme utilities and guides
- Markdown documentation is cataloged for easy access

## Planned Improvements
- Update help app navigation to highlight new theme docs
- Add search functionality for all markdown documentation
- Cross-reference utility functions and code examples in developer help
- Regularly scan `/docs/` and `/apps/help/docs/` for new or updated documentation
- Add quick links to theme guides and developer references on help app homepage

## Developer Section Goals
- Provide actionable references for theme usage and overrides
- Maintain up-to-date guides for new features and changes
- Offer troubleshooting and best practices for theme development

## Feedback & Contributions
- Developers are encouraged to suggest improvements to help app documentation
- Submit new guides or updates to `/docs/` or `/apps/help/docs/`
- Contact the MediaBrain team for support or questions
