# What's New - November 2025

## Theme System Overhaul
- Themes moved from `/css/themes/` to `/themes/` for easier organization and overrides.
- Utility functions in `util.php` for including theme CSS, JS, and audio assets.
- Audio support added for theme-based UI feedback.
- App-level theme overrides supported for all asset types.
- New theme documentation: user guide, utilities reference, roadmap, and overview.

## Developer Help Updates
- Help app now includes all new theme documentation in `/apps/help/docs/`.
- Development help section updated with:
  - Quick reference for theme utility functions and classes
  - Example usage for asset inclusion and overrides
  - Best practices for theme development
  - Troubleshooting tips

## General Improvements
- Markdown documentation scanned and cataloged for easier access
- Help app navigation and search to be updated for new docs
- More cross-references and code examples in developer help
