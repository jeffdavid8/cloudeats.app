# Developer Documentation Hub

Welcome to the MediaBrain developer hub. This is the starting point for all developers and AI assistants.

This documentation is curated from the collective knowledge in `AI-DEVELOPMENT-NOTES.md` and is organized to help you get up to speed quickly.

## 🚀 Getting Started

1.  **[Environment Setup](./01-setup.md)**: First-time setup for the Docker environment, including Nginx proxy and hosts file configuration. **Start here.**
2.  **[Architectural Principles](./02-architecture.md)**: The "why" behind our code. Read this to understand our Drupal-inspired modular design, API patterns, and core philosophies.
3.  **[Developer Cookbook](./03-cookbook.md)**: Practical "how-to" guides for common tasks like adding API endpoints, working with authentication, and logging events.
4.  **[Troubleshooting Guide](./04-troubleshooting.md)**: Solutions for common problems like MIME type errors, connection issues, and session bugs.

## ✍️ Contribution Process

Our documentation is a living project. To keep it current:

1.  **New Knowledge**: Add new discoveries, gotchas, or patterns to `AI-DEVELOPMENT-NOTES.md`.
2.  **Documentation in PRs**: When you submit a pull request, update the relevant document in this hub as part of your changes. The Definition of Done includes documentation.
3.  **Periodic Sync**: On a regular basis, we review the "Raw Knowledge Base" and migrate its contents into the formal documentation here.
